# Library Management System

My React project for the library management assignment.

## How to run
1. Extract the folder
2. Open terminal in the folder
3. Run: npm install
4. Run: npm run dev
5. Open the link in browser (usually http://localhost:5173)

## Features
- Login
- Dashboard with book availability
- Add / Update / Delete books
- Add or deduct stock (transactions)
- User management (admin only)
- Data saved in localStorage
